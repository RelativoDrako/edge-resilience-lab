## Reading rule

The documentation follows the same public logic as the repository:

1. **general first**
2. **specialized second**
3. **evidence before invasive change**

That means:
- start with the cross-platform baseline
- move to the specialized Stream 7 lane only if the device really needs it
- review reports before optimization or migration

## Menu hint rule

Every launcher in this repository should:
- show a short execution hint on startup
- suggest `help`
- remind the operator to run inventory first
- disclose output paths for reports and logs
