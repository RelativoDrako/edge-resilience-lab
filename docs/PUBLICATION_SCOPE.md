# Publication Scope

This repository is suitable for public portfolio review as a Work in Progress architecture reference.

## Included

- Conceptual architecture
- C4 and SysML visual reasoning
- RFP-style evaluation framing
- Roadmap and maturity progression
- Governed AI decision-boundary material
- CI/CD publication automation assets
- Multiplatform inventory and evidence-first tooling
- Legal/IP and publication-boundary notes

## Excluded

- Confidential client or employer material
- Production deployment details
- Private recovery internals
- Unvalidated hardware-specific findings
- Any claim of autonomous decision authority

## Review Rule

A public change is acceptable only if it increases clarity, maturity, safety, or governability without weakening authority guarantees.
