# Architecture Overview

EdgeResilienceLab describes a deterministic control system with constrained AI advisory components.

The public architecture is centered on:

- explicit authority;
- bounded autonomy;
- degradation-aware behavior;
- audit evidence;
- recovery and continuity reasoning;
- governance-first automation.

The core architectural model is supported by C4 and SysML artifacts under `diagrams/`, governed AI materials under `governance/`, automation assets under `automation/`, and evidence-first device discovery tooling under `tooling/`.
