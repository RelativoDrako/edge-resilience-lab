# Integration Decisions

## deploy_edge_resilience_lab

Decision: reuse and enhance as the repository root.

Rationale: it already contains the strongest ERL canonical material: executive positioning, RFP, roadmap, disclaimers, diagrams, examples, automation, and Work in Progress framing.

## governed-ai-architecture

Decision: absorb complete content under `governance/governed-ai-architecture/`.

Rationale: it strengthens ERL's governance layer and supports AI advisory-only and authority-boundary semantics.

## GH_CI-CD

Decision: absorb complete content under `automation/GH_CI-CD/`.

Rationale: it is compact, operationally useful, and supports publication and reproducibility without requiring renaming.

## inventory-stream7-rescue

Decision: absorb public multiplatform tooling, docs, assets, and IP-boundary material under `tooling/inventory-stream7-rescue/`.

Rationale: it provides evidence-first device discovery and assessment discipline relevant to resilient edge operations.

## Naming Policy

Script names are preserved to avoid breaking existing documentation and operational memory.
