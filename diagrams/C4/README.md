# C4 — Context and Container Views

This folder contains C4-style architectural diagrams for **EdgeResilienceLab**.

The purpose of these views is conceptual clarity — not exhaustive system modeling.

## Intended Views

### System Context View

Defines:

- System boundary  
- External actors  
- Environmental interaction  

### Container View

Shows major logical subsystems:

- Control Plane  
- Trust Engine  
- Data Plane  
- Decision Engine  
- Observability  
- Human Authority  

## Diagram Principles

- Simple, high-signal diagrams  
- No implementation-level detail  
- Focus on governance and authority flow  
- Explicit trust and state boundaries  

## Status

Conceptual reference diagrams.  
Additional views may be added if deeper explanation becomes necessary.
