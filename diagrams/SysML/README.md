# SysML — State and Governance Diagrams

This folder contains SysML-style conceptual diagrams describing:

- System state transitions  
- Degradation and recovery modes  
- Authority and governance boundaries  
- Human override paths  

## Modeled Views

### System State Model

Formalizes how the system transitions between:

- Reinforced  
- Optimal  
- Normal  
- Degraded  
- Degraded-Critical  
- Critical (Emergency Continuity)  

These states define how the system protects itself under uncertainty.

### Authority Relationship Model

Illustrates:

- Control Plane sole authority  
- Trust evaluation gates  
- Decision rollback paths  
- Human final authority  

## Modeling Scope

These diagrams:

- Are descriptive, not prescriptive  
- Do not define software implementation  
- Serve architectural reasoning and audit preparation
